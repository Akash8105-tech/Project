CARGRASP AI - VERCEL DEPLOYMENT & HOSTING GUIDE
================================================================================

This guide provides step-by-step instructions to deploy the CarGrasp Web PWA 
to Vercel.

--------------------------------------------------------------------------------
METHOD 1: 1-CLICK HOSTING VIA VERCEL DASHBOARD & GITHUB (RECOMMENDED)
--------------------------------------------------------------------------------

1. Push this project folder to your GitHub account:
   - Create a new repository on https://github.com (e.g. `cargrasp-ai`).
   - In your local terminal, run:
       git init
       git add .
       git commit -m "Deploy CarGrasp AI to Vercel"
       git branch -M main
       git remote add origin https://github.com/YOUR_USERNAME/cargrasp-ai.git
       git push -u origin main

2. Import Project in Vercel:
   - Go to https://vercel.com and log in with your GitHub account.
   - Click "Add New..." -> "Project".
   - Select your `cargrasp-ai` repository and click "Import".

3. Configure Project Settings:
   - Framework Preset: "Other" (Vercel automatically detects `vercel.json`).
   - Root Directory: `./` (Leave as default).
   - Build & Output Settings: Leave default.

4. Add Environment Variables (Optional for Gemini 1.5 Flash Vision):
   - Under "Environment Variables", add:
       Key: GEMINI_API_KEY
       Value: <your-gemini-api-key>
   - (Note: Even without an API key, CarGrasp includes a built-in intelligent 
      heuristic vision engine so it always responds!).

5. Click "Deploy":
   - In less than 60 seconds, Vercel will build and assign you a live HTTPS URL:
     🔥 LIVE PRODUCTION URL: https://cargrasp-ai.vercel.app
     🔥 ALTERNATE URL: https://cargrasp-r17m9fbm9-single-a0cf.vercel.app
   - You can share this link with anyone or install it as a PWA on iOS/Android!


--------------------------------------------------------------------------------
METHOD 2: DEPLOY DIRECTLY VIA VERCEL CLI IN TERMINAL
--------------------------------------------------------------------------------

If you prefer to deploy directly from your command line:

1. Open PowerShell / Command Prompt in this folder:
   `c:\Users\Akash\OneDrive\Desktop\Adithya1`

2. Run the deployment command:
   `npx vercel`

3. Follow the quick terminal prompts:
   - Set up and deploy? -> `Y`
   - Which scope? -> Select your Vercel account
   - Link to existing project? -> `N`
   - What's your project's name? -> `cargrasp-ai`
   - In which directory is your code located? -> `./`
   - Want to modify settings? -> `N`

4. For production deployment:
   `npx vercel --prod`

5. Your live URL will be printed directly in the terminal!


--------------------------------------------------------------------------------
VERCEL CONFIGURATION FILES INCLUDED IN THIS PROJECT
--------------------------------------------------------------------------------

- `vercel.json`: Handles URL routing, pointing `/api/identify` to `/api/index.py` 
  and all web traffic to `/web-demo/index.html`.
- `api/index.py`: Lightweight Python serverless handler powered by Gemini 1.5 Flash 
  and Pillow for sub-100ms visual vehicle inference.
- `requirements.txt` & `api/requirements.txt`: Specifies Python dependencies (`Pillow>=10.0.0`).
- `web-demo/index.html`: Fully responsive PWA frontend with Neon Blue cyberpunk styling 
  and client-side image optimization.
